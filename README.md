# ⛰️ GeoPulse

## Rockfall Prediction & Risk Assessment

GeoPulse is a machine-learning-based rockfall prediction prototype designed to estimate rockfall risk from environmental and geological conditions.

The system uses a Random Forest classifier to estimate the probability of rockfall and converts the prediction into an interpretable risk level.

> **Research project:** GeoPulse: A Low-Cost Machine Learning Rockfall Prediction System

---

## 🎯 Project Objective

Rockfalls can threaten human lives, infrastructure, transportation systems, mining operations, and mountainous regions.

GeoPulse aims to support early risk identification by combining environmental and geological indicators with machine learning.

The research proposes an integrated framework involving:

- Environmental and geological data
- Machine learning prediction
- Probability-based risk assessment
- Risk-level classification
- Visualization
- Early-warning support

---

## 🧠 Machine Learning Approach

The GeoPulse research investigates supervised machine-learning approaches including:

- Logistic Regression
- Random Forest
